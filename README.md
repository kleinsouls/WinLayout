# WinLayout

Windows 11 窗口位置记忆器 —— 把窗口摆好，勾选，存成方案，以后一键整套摆回。

![Windows 11](https://img.shields.io/badge/platform-Windows%2011-blue) ![Python](https://img.shields.io/badge/python-3.9%2B-blue) ![依赖](https://img.shields.io/badge/dependencies-none%20%2F%20%E6%A0%87%E5%87%86%E5%BA%93-brightgreen)

---

## 解决的问题

每次开机或从全屏程序切回来，窗口位置全是乱的——得一个个拖回去。
WinLayout 让你把喜欢的布局**存下来**，之后一个热键就恢复。

## 特性

- **勾选即存** —— 把窗口摆好，勾选它们，存成命名方案
- **一键整套恢复** —— 一个全局热键，任何程序在前台都能触发
- **多方案** —— 「工作台」「写代码」「打游戏」各存一套，切换就是点一下
- **纯标准库** —— 只用 `tkinter` + `ctypes`，无需 `pip install` 任何东西
- **高 DPI 正确** —— Per-Monitor DPI 感知，125%/150% 缩放下坐标不偏移
- **屏幕变化自适应** —— 拔掉副屏或改分辨率，窗口自动等比换算，不会跑出屏幕
- **最大化状态记忆** —— 记录时是最大化，恢复后也是

## 快速开始

### 下载

Releases 页面下载 `WinLayout.exe`，双击运行，无需安装、无需 Python。

### 使用

1. 先用鼠标把各个窗口摆到你习惯的位置
2. 点「🔄 刷新窗口」，在左边列表里**点最左边的方框**勾选要记住的窗口
3. 点「💾 存入为新方案」，起个名字（比如 `工作台`）
4. 以后**按 `Ctrl+Alt+R`**，整套窗口立刻回到方案里的位置

## 命令行

```
WinLayout.exe                     打开界面
WinLayout.exe --restore [名称]     静默恢复方案（省略名称则用上次的）
WinLayout.exe --list              列出所有方案及其中的窗口
WinLayout.exe --path              配置文件位置
WinLayout.exe --del 名称          删除某个方案
```

`--restore` 可以在 Windows 任务计划里加一个「用户登录时」触发的任务，实现开机自动摆好窗口。

## 从源码运行

需要 Python 3.9+，不需要安装任何第三方包。

```bash
python winlayout.py                      # 直接运行
python -m PyInstaller --clean --noconfirm WinLayout.spec   # 打包成 exe
```

## 工作原理

- **窗口枚举** —— `EnumWindows` 拿到所有顶层窗口，用 `QueryFullProcessImageNameW` 读出进程名，按进程名匹配
- **位置记忆** —— 记录窗口的绝对坐标，同时额外记下当时所在显示器的设备名和工作区尺寸
- **恢复时换算** —— 同屏同尺寸则像素级精确还原；换屏或分辨率变了，按窗口相对位置的比例换算到新屏；记录时的屏幕已不存在则落到主屏换算，并保证窗口完整落在屏内
- **DPI 感知** —— 启动时调用 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`

## 配置文件

`%APPDATA%\WinLayout\schemes.json`，普通 JSON，可手动编辑或备份。

## 已知限制

- 按**进程名**匹配，同一程序在一个方案里只记一个窗口。比如 Chrome 开多个标签页时只记一个——这类程序关掉重开会自己恢复标签页，硬摆窗口反而打架
- 少数程序不接受外部强制改变窗口大小（部分游戏、全屏程序）
- 修改全局热键后需要重启程序生效
